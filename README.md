# Pizza Hub

An Android application concept for ordering pizzas online, with Firebase Authentication for user sign-in.

## Overview

Pizza Hub was built as an academic/personal project to explore mobile application development and the core flow of an online pizza-ordering experience.

## Highlights

- Android application for a pizza-ordering use case
- Firebase Authentication integration
- Mobile app development and service integration

## Tech Stack

- **Platform:** Android
- **Authentication:** Google Firebase Authentication
